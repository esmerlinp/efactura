# Tutorial: Exportación contable

Exporta tus ventas y gastos como asientos contables para usarlos en un software
contable externo.

## Cómo entrar

1. En el menú lateral, abre **"Reportes"** → categoría **Contables** →
   **"Exportación contable"**.

## Exportar ventas o gastos

1. Elige **"Exportar Ventas"** o **"Exportar Gastos"**.
2. Selecciona el **Formato**: CSV Estándar (Excel), QuickBooks (IIF/QBO),
   Sage 50 (Pez), Odoo o Softland.
3. Define las fechas **Desde** / **Hasta**.
4. Haz clic en el botón de exportar correspondiente.

## Plan de cuentas

Usa el editor **"Plan de Cuentas"** para mapear tus cuentas al formato del
software destino, y haz clic en **"Guardar Plan de Cuentas"**.

## Consejos

- Verifica el mapeo de cuentas antes de exportar para que los asientos lleguen
  correctos al sistema externo.
