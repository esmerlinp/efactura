# Tutorial: Posiciones y departamentos

Define la estructura organizacional: puestos (posiciones) y departamentos.

## Posiciones

1. En el menú lateral, abre **Administración** y haz clic en **"Posiciones"**.
2. Para crear una posición:
   - Escribe el **nombre** en **"Nueva posición"**.
   - Opcionalmente, elige **"Reporta a"** para indicar el puesto superior.
   - Haz clic en **"Agregar"**.
3. Para editar:
   - **"Guardar nombre"** para cambiar el nombre.
   - **"Guardar"** para cambiar a quién reporta.
   - **"Guardar horario"** para definir el horario semanal (L–D).

## Departamentos

1. En el menú lateral, abre **Administración** y haz clic en **"Departamentos"**.
2. Escribe el nombre del departamento y haz clic en **"Agregar"**.
3. Para renombrar o eliminar, usa los íconos de la fila (editar / eliminar).

## Consejos

- Define las posiciones y departamentos antes de cargar empleados, para
  asignarlos al crearlos.
- El organigrama se construye automáticamente a partir del campo **"Reporta a"**.
