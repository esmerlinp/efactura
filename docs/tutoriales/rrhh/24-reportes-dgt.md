# Tutorial: Reportes DGT / SIRLA

Genera los formularios del Ministerio de Trabajo (DGT) para el sistema SIRLA.

## Cómo entrar

1. En el menú lateral, abre **"Reportes"**.
2. En la categoría **"Nómina"**, elige el formulario que necesitas:
   - **DGT-3: Personal Fijo** — planilla de empleados fijos.
   - **DGT-4: Cambios en Personal Fijo** — altas y bajas.
   - **DGT-2: Horas y Vacaciones**.
   - **DGT-5: Personal Ocasional**.
   - **DGT-11: Comunicación de Ingreso**.
   - **DGT-12: Comunicación de Cese**.

## Generar un formulario

1. Selecciona el **Año** y el **Mes**.
2. Revisa los datos (empleados, salarios, ocupación, fechas).
3. Exporta en el formato que necesites:
   - **".txt (SIRLA)"** — para cargar en el sistema del Ministerio de Trabajo.
   - **".xlsx"** — para revisar en Excel.
   - **".pdf"** — para imprimir o archivar.

## Notas

- El formulario **DGT-9 (Suspensión)** aparecerá próximamente.
- Verifica que tus empleados tengan completos los campos de SIRLA (nivel
  educativo, nacionalidad, código ocupación, etc.) para que el reporte salga
  correcto. El sistema te los muestra como **Incidencias**.
