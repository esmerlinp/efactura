# Tutorial: Terminal de ventas (POS)

El terminal de ventas te permite registrar ventas rápidamente, como en una caja
registradora.

## Abrir el terminal

1. Con el turno abierto, haz clic en **"Abrir Terminal de Ventas"** (o entra a
   **Punto de Venta (POS) → Terminal**).

## Registrar una venta

1. **Cliente**: escribe el RNC/Cédula o deja **"Consumidor Final"**.
2. **Productos**: escribe el **código o SKU** (o escanéalo) y agrega los
   productos al carrito. También puedes tocar las categorías y seleccionar del
   listado.
3. Revisa el carrito con los totales (Subtotal, ITBIS, **TOTAL GENERAL** y su
   equivalente en USD).

## Cobrar

1. Indica el **Monto Recibido** (o usa los botones de **Dinero Rápido**:
   RD$100/200/500/1000/2000 o **"Exacto"**).
2. Revisa la **Devuelta**.
3. Elige el método de pago:
   - **"Efectivo"**, **"Tarjeta"**, **"Transferencia Bancaria"** o **"Cobrar en
     USD (Dólares)"**.

## Finalizar

1. Al completarse verás **"¡Venta Registrada con Éxito!"**.
2. Puedes **"Imprimir Ticket (80mm)"** o iniciar **"Nueva Venta"**.

## Puntos a tener en cuenta

- Si una operación requiere autorización, se abrirá la ventana **"Autorización
  Requerida"** (selecciona el supervisor y escribe su PIN).
- Usa **"Cancelar Venta"** para descartar el carrito actual.
