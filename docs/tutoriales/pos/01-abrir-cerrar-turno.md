# Tutorial: Abrir y cerrar turno de caja (POS)

Antes de vender en el Punto de Venta debes abrir un turno de caja con un fondo
inicial. Al terminar, cierras el turno.

## Abrir un turno

1. En el menú lateral, abre **Ventas → Punto de Venta (POS)**.
2. En la tarjeta **"Apertura de Turno de Caja"**:
   - Selecciona la **Caja Registradora**.
   - Escribe el **Fondo Inicial de Caja (RD$)**.
3. Haz clic en **"Abrir Turno de Caja"**.

Verás el aviso **"Turno Activo"** con el nombre de la caja, la hora de apertura
y el fondo inicial.

## Cerrar un turno

1. Con el turno abierto, haz clic en **"Cerrar Turno"** (o en la tarjeta
   **"Cerrar Turno (Arqueo)"**).
2. Completa el arqueo (ver tutorial de **Arqueo y cierre de caja**).
3. Confirma el cierre.

## Si aún no tienes una caja

- Usa el enlace **"Nueva Caja"** (solo propietario) para crear una caja
  registradora.
- Desde **"Administración de Cajas"** puedes gestionar las cajas existentes.

## Puntos a tener en cuenta

- No puedes vender sin un turno abierto.
- El **Modo Consolidado** agrupa las ventas de varias cajas (ver administración).
