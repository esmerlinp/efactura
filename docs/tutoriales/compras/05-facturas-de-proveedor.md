# Tutorial: Facturas de proveedor (CxP)

Registra las facturas de tus proveedores para llevar el control de cuentas por
pagar.

## Crear una factura de compra

1. En el menú lateral, abre **Compras → Facturas de proveedores**.
2. Haz clic en **"+ Nueva Factura de Compra"**.
3. Completa el proveedor y agrega las partidas con **"Añadir Partida"**.
4. Define el **Estado del Pago** (Pagado / Pendiente).
5. Si aplica, usa el modal **"Retenciones, Descuentos y Recargos"** para
   retenciones ISR/ITBIS.
6. Haz clic en **"Guardar"** (o **"Guardar y Nuevo"**).

## Gestionar las facturas

- Filtra por estado: **Pagado / Pendiente / Abonado / Vencido**.
- Usa **"Exportar CSV"** para descargar el listado.

## Puntos a tener en cuenta

- Las facturas con estado **Pendiente** alimentan tu CxP (cuentas por pagar).
- Puedes crear una factura directa o facturar una orden de compra ya recibida.
