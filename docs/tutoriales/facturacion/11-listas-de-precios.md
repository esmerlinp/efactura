# Tutorial: Listas de precios

Las listas de precios te permiten manejar diferentes precios según el tipo de
cliente (por ejemplo, precio público vs. mayorista).

## Cómo entrar

1. En el menú lateral, abre **Ingresos → Listas de Precios**.

## Crear una lista

1. Haz clic en el botón de nueva lista.
2. Define el nombre de la lista (ej. "Mayorista", "Público general").

## Asignar precios

1. Agrega los productos y define su precio en la lista.
2. Guarda.

## Usar la lista

- Al crear un cliente, asigna su **Lista de Precios** predeterminada.
- Al facturar, el sistema aplicará los precios de la lista del cliente.

## Consejos

- Usa listas para diferenciar precios por segmento (minorista, mayorista,
  distribuidor).
- Si un cliente no tiene lista, se usa el precio público del producto.
